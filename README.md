# Polaroid Haflah Event
Platform dokumentasi foto acara: tamu scan QR, kirim foto, galeri Classic Polaroid, dashboard admin.
Stack: HTML/CSS/JS Vanilla (GitHub Pages) + Google Apps Script + Google Sheets + Google Drive.

- `site/`    : frontend (dipublish ke GitHub Pages lewat GitHub Actions)
- `backend/` : Google Apps Script
- `docs/`    : dokumentasi
